SP_ORG_Items 0.13-A vs 0.12 FINAL

BASELINE
- 0.12 FINAL — Integration Freeze homologada manualmente.

DELTA FUNCIONAL
- Biblioteca PÚBLICOS continua SESSION-scoped.
- Em multiplayer, cliente não muta mais a biblioteca pública diretamente.
- PUBLICAR no cliente envia snapshot validado ao servidor.
- Servidor deriva autor real via remoteExecutedOwner -> player owner -> getPlayerUID/name.
- Servidor valida e comita criação/atualização, controla publicId e revision e replica o estado público.
- Cliente recebe callback server-only e atualiza ENVIADO -> PUBLICADO/FALHA.
- SP/host preserva caminho síncrono local e compatibilidade da UX D.7.x.

SEGURANÇA
- CfgRemoteExec adiciona somente dois endpoints nominados.
- Endpoint de request aceita alvo server-only (allowedTargets=2).
- Callback aceita alvo client-only (allowedTargets=1).
- Handler do servidor exige isRemoteExecuted + remoteExecutedOwner associado a allPlayers.
- Callback do cliente rejeita origem remota diferente do servidor (owner 2).
- Overrides de autor permanecem apenas no caminho local/server para compatibilidade de fixtures; cliente remoto não os envia.

INTENCIONALMENTE NÃO ALTERADO
- functions/application
- functions/inventory
- functions/draft
- functions/storage
- functions/catalog
- UI DnD handler / transfer command / physical row command
- Whole-Kit, EXACT, rollback, capacity, load semantics, Equipment View e applicationTarget

FORA DO ESCOPO
- JIP/reconciliation explícita;
- persistência de servidor;
- ACL/moderação;
- rate limit/retry/timeout/recovery;
- integração cross-module.
